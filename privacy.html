Политика конфиденциальности Marfa

Действует с 25 октября 2026 года.

Кто пользуется программой

Marfa — личная программа владельца подключённого аккаунта Google. Посторонние пользователи не регистрируются и доступа к ней не получают.

Какие данные Google использует программа

  • Gmail: письма владельца (отправитель, тема, дата, текст) — чтение; черновики и отправка писем владельца — только по его подтверждению;
  • Google Календарь: события владельца — чтение; создание событий — только по его подтверждению.

Программа не запрашивает доступ к Google Диску, Документам, Таблицам и Контактам, не удаляет письма и не меняет ярлыки.

Как используются данные

Только чтобы показать владельцу краткий пересказ и перевод писем, предложить черновик ответа и события календаря и по его подтверждению отправить письмо или создать событие. Данные не используются для рекламы, не продаются и не публикуются.

Где обрабатываются и хранятся данные

Данные обрабатываются на сервере владельца. Для пересказа и перевода текст писем передаётся сервису искусственного интеллекта, которым пользуется владелец (OpenAI), — только для подготовки ответа владельцу. Ключи доступа к Google хранятся на сервере владельца и никому не передаются. Рабочие записи программы доступны только владельцу.

Соответствие правилам Google

Использование и передача данных, полученных через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Владелец может в любой момент отозвать доступ в настройках аккаунта Google: myaccount.google.com/permissions.

Контакты

Вопросы — по адресу поддержки, указанному на экране согласия Google.

На главную · Условия использования

Marfa accesses only the owner's Gmail (reading; drafts and sending only after the owner's confirmation) and Google Calendar (reading; creating events only after confirmation). Data is used only to provide summaries, translations, reply drafts and event suggestions to the owner; message text is processed by the AI service the owner uses (OpenAI) solely for that purpose. Data is not sold, not used for advertising and not shared otherwise. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
